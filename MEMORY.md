# Memory & Observations
- The project is migrating to BobUI.
- Routing is handled via `mRouteId` and `mPersistentId`.
- Submodules: `muse_framework`, `bobui`.
- Realtime effects are separated into PreFader and PostFader.
- UnifiedDashboard (`UnifiedDashboard.qml`) consolidates Projects, Workspaces, Quick Actions, Cloud sync, and Audio Engine Server controls into a single page.
- Native System Tray integration is implemented in `SystemTrayController` (`src/appshell/view/systemtraycontroller.h/.cpp`) using `QSystemTrayIcon`.
- The user prefers continuous autonomous execution, extremely detailed documentation, and regular commits.
